# Work Log

> Write this **as you go**, at the end of each working session. Not on day 7.
>
> We read this file closely. The most interesting entries are the ones where
> something went wrong — those tell us how you work far better than the ones
> where everything succeeded.
>
> A zero-hour day, honestly recorded, is completely fine. An invented day is
> not, and it is more obvious than people think.
>
> Keep each entry short. Five to ten lines is plenty.
